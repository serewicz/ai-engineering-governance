Version 0.1.0 candidate. Every box needs evidence; checking a box does not grant authority.
The report uses the same B01–B18 IDs and PASS, FAIL, BLOCKED or NOT RUN.

- [ ] **B02 — Owner:** Select separately approved governance/bootstrap pins; name administration and recovery owners. Evidence: ____________________.

- [ ] **B04 — Codex:** Validate manifest and compare existing stronger controls; contradictions block adoption. Evidence: ____________________.
- [ ] **B05 — Codex:** Review deterministic dry-run files, hashes and control differences without privileged operations. Evidence: ____________________.
- [ ] **B06 — Codex:** Prepare disabled bootstrap PR; run deterministic tests and exact-head CI. Evidence: ____________________.
- [ ] **B07 — Owner:** Designate independent Principal and task-specific Security QA; no source-project designation reuse. Evidence: ____________________.
- [ ] **B08 — Codex:** Record actual independent exact-head dispositions; resolve findings and revalidate every changed head. Evidence: ____________________.

- [ ] **B10 — Owner:** Organization setup: verify GitHub issuer, provider administration, billing and incident ownership. Evidence: ____________________.
- [ ] **B11 — Owner:** Per project: create dedicated workspace/account/production and authentication-only rules with exact trust restrictions. Evidence: ____________________.
- [ ] **B12 — Owner:** Enter separate scoped publishing/OpenAI credentials directly in GitHub; verify saved provider limits. Evidence: ____________________.
- [ ] **B13 — Codex:** Inspect effective protections, plan capabilities and bypass actors; Owner resolves mandatory controls or permitted exceptions. Evidence: ____________________.
- [ ] **B14 — Codex:** Verify authenticated budget metering, atomic reservations, invocation bounds and isolation, including denial cases. Evidence: ____________________.
- [ ] **B15 — Owner:** Authorize authentication-only testing; Codex executes signed positive/negative checks with inference forbidden. Evidence: ____________________.
- [ ] **B16 — Owner:** Authorize dedicated synthetic integration scope; Codex verifies draft PR, triggered CI and exact-SHA review. Evidence: ____________________.
- [ ] **B17 — Codex:** Record readiness for every step with exact evidence and prove smoke authorization cannot dispatch product work. Evidence: ____________________.
- [ ] **B18 — Owner:** Authorize production activation and separately approved task; otherwise execution stays disabled. Evidence: ____________________.

One-time organization prerequisites are B10 and shared administration policy. B11–B18 are per-project.
No code, task approvals, issue digests, credentials or reviewer designations carry over from references.
30-minute hands-on onboarding is a target to measure after release and prerequisite availability;
review/CI waits, account procurement, billing decisions and unsupported integration repairs are excluded.
It has not been measured or achieved by this candidate.
